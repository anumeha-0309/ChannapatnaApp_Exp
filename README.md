
# Channapatna – Namma Pride

Channapatna – Namma Pride is an Android application developed using Kotlin and Generative AI to promote and preserve traditional Channapatna wooden toys. The application focuses on improving artisan visibility, creating awareness about eco-friendly handcrafted products, and providing an interactive multilingual user experience.



## Features

* Toy Verification Module
* AI-Based Storytelling using Google Gemini API
* Meet the Maker Feature
* Multilingual Support
* Responsive UI/UX Design
* Information on Traditional Toy Manufacturing Process



## Technologies Used

* Kotlin
* XML
* Android Studio
* Google Gemini API
* RecyclerView
* GridLayoutManager
* Material Design Components
